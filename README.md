# Yens Castro Portfolio

A single-page personal portfolio for Yens Castro, a Computer Science student at Arizona State University. The page highlights experience, technical skills, projects, and contact information.

## Features

- Responsive layout for desktop and mobile screens
- About, skills, projects, and contact sections
- Project links to GitHub repositories
- Contact form connected to Formspree

## Run Locally

From the project folder, start a local web server:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000) in a browser.

## Deployment

The site is hosted with GitHub Pages:

[https://yenscastro.github.io/01-prj-personal-site/](https://yenscastro.github.io/01-prj-personal-site/)

To update the site, edit the files, commit the changes, and push to the `main` branch.
